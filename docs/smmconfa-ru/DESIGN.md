## 7. Сетка, отступы, радиусы, тени

### 7.1 Контейнеры

```css
.container { max-width:1600px; width:100%; padding:0 20px; margin:0 auto; }
@media(max-width:1570px){ .container{ max-width:1240px; } }
@media(max-width:641px){  .container{ padding:0 10px; } .wrap_container{ width:calc(100% - 6px); } }

.wrap_container { max-width:calc(1920px - 80px); width:calc(100% - 80px);
                  margin:0 auto; border-radius:30px; }
```

- Часть секций сужает контейнер до 1240px точечно: `.countdown_timer_block .container`, `.mcs_block .container`, `.free_stream_block .container`.
- Блоки «второго поколения» (партнёры, спикер) игнорируют `.container`: `body.partners_v2 .block { width:1560px; margin:0 auto; }`.

### 7.2 Ритм секций

| Контекст | Десктоп | Мобильный |
|---|---|---|
| Обычная секция | `padding: 90px 0` | `30px 0` |
| Внутренние страницы (`page_block`) | `110px 0` | `30px 0` |
| Hero главной | `180px 0 40px` (на низком экране 240px) | `150px 0 30px` |
| Первый контейнер внутренней страницы | `padding-top: 40px` | — |
| Плотные блоки (темы, отзывы, about) | `40px 0` | `30px 0` |

Чередование: белая секция → чёрная секция → белая. Чёрные: тарифы, спикеры, «кому», качества, рассылка, бесплатный поток. Это главный приём ритма страницы.

### 7.3 Сетки карточек

- Флекс с отрицательными полями: контейнер `margin: 0 -10px`, карточка `margin: 10px`.
- 3 колонки: `width: calc(100% / 3 - 20px)` (тарифы).
- 2 колонки: `width: calc(100% / 2 - 20px)` (отзывы).
- 4 колонки и слайдеры — через Slick (`js/slick.min.js`).
- В v2: `width: calc((100% - 20px * 2) / 3)` + `margin: 0 20px 20px 0`, каждая 3-я без правого отступа.

### 7.4 Радиусы

| Значение | Где |
|---|---|
| `4px` | кнопки, вкладки, карточки v2, плашки с датами |
| `5px` | поля «старого» типа (`.input--lg`) |
| `10px` | фото спикера, карточки, попапы, тёмная плашка «о форуме» |
| `20px` | тарифы, отзывы, тёмные панели, `border-radius` фото-карточек |
| `30px` | `.wrap_container` (крупная тёмная панель) |
| `35px` / `100px` | пилюли тем (`theme_item`, темы партнёров) |
| `50%` / `100%` | круги: иконки в пилюлях 66px, кнопка-бургер, планета, аватары |

### 7.5 Тени и глубина

- Теней нет: единственный `box-shadow` в системе — `0 0 1px 0 var(--r)`.
- Градиентов нет (`gradient` в `style.css` — 0 вхождений).
- Глубина — только за счёт: чёрных секций, рамок 2px, красных плашек, наклонного «срезанного угла» у карточек v2.

### 7.6 Паттерны страниц

**Главная.** Тёмный hero на фото (`img/intro_bg.jpg`, затемнение), поверх — заголовок-плакат, дата/место с иконками, статистика 70px, две кнопки. Дальше чередование белых и чёрных секций: о форуме → темы-пилюли → преимущества → спикеры (чёрная) → тарифы (чёрная) → отзывы → партнёры → место проведения → подвал.

**Внутренняя страница.** Фиксированная чёрная шапка, отступ 40px, заголовок `h1` 64px капсом, контент 110px по вертикали. Цветовая схема — белая; красный только в заголовке и ссылках.

**Страница спикера (v2).** `body.speaker_v2`: блок 1560px, заголовок 84px с красной второй строкой, подзаголовок 32px, далее секции `.sp*_container` с карточками на `#F6F6F6`, рамкой 2px `#E8E8E8` и «срезанным углом» (см. ниже), красные карточки — заливка `#FF3838` + рамка `#D60000`.

**Как устроен «срезанный угол».** Это не плашка и не декор. Псевдоэлемент `:after` 100×60px повёрнут на 40° и сдвинут за угол (`right: -33px; top: -23px`); карточка имеет `overflow: hidden` и обрезает его. Внутри карточки остаётся только **диагональ** — от точки 72px левее правого края на верхней кромке до 60px ниже верхнего края на правой кромке, то есть под 40° к горизонту. Срезается **правый верхний** угол, площадь среза ~72×60px.

Заливка псевдоэлемента должна совпадать с фоном секции (на сайте — белый): она закрывает угол карточки вместе с её рамкой. Поэтому на тёмной секции приём не применяется, а в токенах цвет вынесен в `--cut-bg`. Линию рисуем только по диагонали (`border-bottom`), остальные стороны не нужны — они всё равно уходят за границу карточки, а их видимость даёт эффект «лишнего прямоугольника». Источник: `.partnerswhy_item` и `.spselection_item` в `css/style.css`.

**Страница программы.** Отдельный CSS (`program.css`), белый фон, таблица с горизонтальным скроллом, красные шапки дней, токены `--p1…--p5`. Ячейки докладов без фона, серый (`#F6F6F6`/`#A8A8A8`) — только у строк-перерывов.

**Лендинг «Топ».** Единственное место с `Liberation Mono`, блок фиксированной ширины 1200px, форма из 3 полей 80px.

## 9. Адаптив и доступность

### 9.1 Брейкпоинты

Фактически используемые (по частоте): **641px** (39 правил — основной мобильный), **1570px** (19 — сужение контейнера и шапки), 1299 / 1300, 1279, 1240–1250, 1199–1200, 1180, 1000–991, 750–767, 1400, 1550, 1600, 1650, 1800, 1921.

Практическая логика:
- `>1570` — контейнер 1600px, крупная типографика, полное меню.
- `1570–1000` — контейнер 1240px, меню сжимается (18 → 16 → 14 → 11px), телефон 24 → 16px.
- `1228` — перестройка подвала в центрированную колонку, скрытие декоративной планеты.
- `≤641` — мобильная версия: секции 30px, заголовки 32px, кнопки 66px, одна колонка, бургер.

**Важная особенность:** в `header.php` стоит JS-подмена viewport — при `screen.width < 1300` страница принудительно рендерится как 1024/768/375px и масштабируется. Поэтому на планшетах и в узких окнах десктопа включается мобильная вёрстка; учитывайте это при проверках.

## Заметки

### Карта файлов

| Файл | Что внутри | Когда грузится |
|---|---|---|
| `css/style.css` | вся система: токены, шапка, секции, кнопки, формы, попапы, подвал, v2-страницы | на всех страницах |
| `css/adaptive.css` | адаптив (дубликат `style_adaptive.css`) | на всех страницах |
| `css/program.css` | таблица программы, свои токены `--p1…` | на страницах программы |
| `css/activity.css` | страницы активностей | на страницах активностей |
| `css/style.min.css` | устаревшая минифицированная копия | **не используется** |
| `js/app.js` | меню, попапы, скролл шапки, маска, валидация | на всех страницах |

### Две генерации стилей

1. **Легаси (главная и старые страницы).** Радиусы 10/20/30, крупный `h3` 84px с трекингом `-5px`, фото в рамке, `.wrap_container` на 30px, фоны-фотографии. Здесь живут `intro_*`, `advantage_*`, `tickets_*`, `speakers_*`, `reviews_*`.
2. **v2 (партнёры, страницы спикеров, лендинги).** Фиксированный блок 1560px, заголовки 84px `-0.06em`, подзаголовки 32px, текст 20px/1.4, карточки 4px на `#F6F6F6` с рамкой 2px `#E8E8E8` и «срезанным углом», красные карточки с рамкой `#D60000`, попапы с прямыми полями 46px.

Новые страницы делать по v2: это самый свежий слой и он используется на ключевых страницах 2026 года. Легаси-блоки не переписывать без задачи.

### Чего в системе нет (не добавлять «от себя»)

- Теней и градиентов.
- Скруглений больше 30px, кроме пилюль и кругов.
- Синего, зелёного, жёлтого и любых «сервисных» цветов, кроме ошибки `#F74200`.
- Строчных заголовков — только капс.
- Второго шрифта — `Liberation Mono` только для лендинга «Топ».
- Иконок-линий тоньше 1.5px и цветных иконок в интерфейсе (только белые/красные).

### Чек-лист новой страницы

1. Обёртка `page_wrapper`, шапка с классом `dark`, отступ сверху — `padding-top: 40px` у первого контейнера.
2. Секции — `.container` (1600/1240px), вертикальный ритм 90px (мобильный 30px).
3. Заголовок — `h1` 64px капсом, `-3px`; если страница v2 — `block_title` 84px `-0.06em` с красной частью через `<strong>`.
4. Кнопки — `.btn .v1` (основная) и `.btn .v4` (контурная красная), в группе `.btn_group`.
5. Карточки — светлые `#F6F6F6` + рамка 2px `#E8E8E8`, радиус 4px; акцентная — красная с рамкой `#D60000`.
6. Текст — 18–20px, `line-height: 1.4`, вторичный — не светлее `#6B6B6B`.
7. Формы — тёмная плашка, поля 46px, без радиусов, ошибка `#F74200`.
8. Проверить на 1440, 1200, 992 и 375 (мобильная вёрстка включается при ширине экрана < 641px).
