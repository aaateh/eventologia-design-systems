# Дизайн-система SOLD OUT

> Источник: локальный бэкап `site-static/` (тема WordPress) · style.css — 1823 строки, program.css — 198 строк · проверено 12/11/2026
> Живой гайд: [index.html](index.html) · Сайт: [soldoutconf.ru](https://soldoutconf.ru/)

Тёмная афишная сцена, один оранжевый акцент, крупная конденсата Alumni Sans и текстовый Montserrat. Прямые углы, линии 1px, минимум теней. Все демо в гайде изолированы классом `.sd`, чтобы не конфликтовать с документацией.

## 1. Палитра

### Ядро

| Токен | HEX | Роль | Контраст |
|---|---|---|---|
| `--o` | `#F74200` | действия, даты, цифры, активные состояния | 5.53:1 на `#090316` — AA |
| `--y` / `--g` | `#E8E3DD` | поверхности карточек и секций | 15.89:1 с `#090316` — AAA |
| `--w` | `#FFFFFF` | основной текст, заливка вторичных кнопок | 20.27:1 на `#090316` — AAA |
| `--b` | `#090316` | фон страницы и тёмные поверхности | база |

`--g` — точный дубль `--y`. В новом коде оставить один `--color-beige`.

| HEX | Где встречается |
|---|---|

Легаси-цвета относятся к модулю программы. В новом дизайне не использовать.

### Правила

- Оранжевый на белом — только крупным кеглем: 3.66:1.
- Белый на оранжевом — только ≥24px или ≥18.66px/700. У кнопки 18px/600 контраст на границе.
- Оранжевый на беже — 2.87:1, для текста запрещён. Заменять на `#090316`.
- `#ABABAB` — только линии.

## 2. Типографика

| Семейство | Роль | Начертания |
|---|---|---|
| **Alumni Sans** | заголовки h4–h6, крупные цифры, плашки | 600, uppercase, line-height .8 |
| **Montserrat** | текст, интерфейс, подписи | 400 / 500 / 600 / 700 (в теме 9 весов × 2 = 18 файлов) |

| Роль | >1920px | ≤1920px | ≤1000px | ≤641px |
|---|---|---|---|---|
| h4 | 180px | 9.375vw | 9.375vw | 42px |
| h5 | 100px | 5.2vw | 5.2vw | 36px |

- В CSS темы нет h1–h3 — только h4–h6.
- Заголовки всегда uppercase, без letter-spacing, line-height не ниже .8.
- `br` в заголовках скрывается на мобайле (`.br_mob`, `br { display: none }`).
- `p = 1.14vw` даёт 12.5px на 1100px. В гайде — `max(12px, 1.14vw)`, чтобы на 1024px не было 11.67px; на ≤1000px — 16px.

### Брейкпоинты

Реальные значения: `1920, 1560, 1525, 1440, 1410, 1400, 1350, 1250, 1200, 1024, 1000, 991, 900, 769, 768, 750, 641, 614, 480`.

Ключевые:

| px | Что меняется |
|---|---|
| 1350 | шапка → бургер, полноэкранное меню |
| 1000 | `p` → 16px |
| 641 | мобильная типографика, padding 10px, marquee 40px |
| 480 | спикеры в одну колонку |

19 значений, из них 9 одноразовых. Рекомендуется свести к пяти: **1440, 1200, 991, 768, 641** и заменить остальные на `clamp()`.

## 13. Доступность

| Пара | Контраст | Вердикт |
|---|---|---|
| `#FFFFFF` на `#F74200` | 3.66 | только крупный текст |
| `#F74200` на `#090316` | 5.53 | AA |
| `#090316` на `#E8E3DD` | 15.89 | AAA |
| `#F74200` на `#E8E3DD` | 2.87 | FAIL |
| `#090316` на `#FFFFFF` | 20.27 | AAA |
| `#FFFFFF` на `#090316` | 20.27 | AAA |
| `#FFC55A` на `#090316` | 12.92 | AAA (легаси) |
| `#6996CD` на `#090316` | 6.61 | AA (легаси) |
| `#ABABAB` на `#FFFFFF` | 2.30 | только линии |

Находки:

1. Глобальный `outline: none` — high.
2. Все `alt=""`, включая фото спикеров и отзывы — high.
3. Поля без label — high.
4. `user-scalable=0` на мобиле — high.
5. Белый текст на оранжевом 3.66:1 при 18px / 600 — mid.
6. Оранжевые заголовки на беже 2.87:1 — high.
7. `p = 1.14vw` → 12.5px на 1100px — mid.
8. Нет `prefers-reduced-motion` — mid.
9. `.buy_mob` 28px и крестик 20px меньше 44px — low.

Чек-лист: контрасты AA, label/aria-label, видимый focus, масштаб 200%, alt для фото, reduced motion и цели 44×44.
