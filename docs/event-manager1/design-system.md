## 1. Характер и принципы

Страница сделана как **афиша большого события**: контрастные тёмные и светлые полосы, очень крупные ExtraBold-заголовки, горячий оранжево-красный градиент только на действиях, много «воздуха» и фотографий.

Ключевые принципы:

1. **Чёрное и белое — основа, оранжевый — событие.** Оранжевый появляется только там, где нужно действие или акцент: кнопка, цена, ссылка, маркер списка, соцсети. Никакого оранжевого декора «просто так».
2. **Прямые углы.** Карточки, кнопки, бейджи, поля — без скруглений. Единственные круглые формы — аватары экспертов и кнопка закрытия попапа.
3. **Толстая типографика.** Заголовки — Montserrat ExtraBold 800, крупно (36–50 px), с ручными переносами. Текст — 15–18 px, спокойный.
4. **Полосы-секции.** Белая → серо-зелёная → белая → светло-голубая → чёрная → белая → чёрная. Ритм задаёт цвет фона, а не рамки и тени.
5. **Фото и люди — главный визуальный контент.** Круглые портреты, живые фотографии событий, скриншоты/сертификат.
6. **Минимум эффектов.** Только смена цвета за 0.2 s. Никаких теней, кроме фото сертификата, и никаких анимаций появления.

### Вертикальный ритм

- Секции: `padding: 90px 0` (крупные — 100 px, финальная форма — 75–80 px).
- Между заголовком и контентом: 36–58 px.
- Между карточками в сетке: 25–30 px.
- Внутри карточек: 20–35 px.

### Сетки

- 4 колонки — факты, обучение, преимущества, тарифы. Ширина колонки `calc((100% - 30px * 2) / 4)` или `25%` с внутренним padding.

- 2 колонки — текстовые блоки «текст + карточка/фото» (520–570 px каждая).
- Одиночная колонка — формы (470 px) и текстовые страницы.

### Брейкпоинты

`1400px` → `1270px` → `1100px` → `1000px` → `750px`. Мобильная версия — жёсткий viewport **360 px** (не резиновый), поэтому на 390 px по краям остаются поля. Хедер на мобильных превращается в бургер, кнопки первого экрана — на всю ширину.

## 6. Состояния и движение

- Все интерактивные элементы: `transition: 0.2s` только для `color`, `background`, `border-color`.
- Ховер текстовых ссылок и меню: `#ff5f01`.
- Ховер прозрачных кнопок: инверсия (белая → чёрный текст, чёрная → белый текст).
- Ховер градиентных кнопок в исходнике **не задан** — визуально кнопка не меняется. Для новых работ recommended: затемнение градиента на 6–8 %.
- `outline: none` стоит глобально — фокус не виден. Для новых работ обязательно добавить `:focus-visible` (2 px `#0099ff`, offset 2 px).

---

## 7. Доступность: что учесть

1. **Контраст CTA.** Белый текст на градиенте — 2.6–4.0:1. Для мелких кнопок это ниже AA. Решение: 16 px / 700 + затемнение градиента или тёмный текст на светлых участках.
2. **Оранжевые ссылки на белом** — 3.14:1. Допустимо только для крупного текста; для обычного — `#646464` с подчёркиванием.
3. **Плейсхолдеры** `#969696` на белом — 2.96:1. Затемнить до `#646464`.
4. **Фокус.** Глобальный `outline: none` — клавиатурная навигация не видна. Добавить `:focus-visible`.
5. **Изображения.** У части `<img>` пустой `alt` — декоративные фото допустимы, но портреты экспертов и логотипы событий должны иметь осмысленный `alt`.
6. **Мобильный viewport 360 px** — при 320 px контент обрежется; стоит сделать резиновую версию.

## 8. Токены

- `tokens/tokens.css` — CSS-переменные (`--em-*`): палитра, типографика, отступы, формы, тени, движение.
- `tokens/tokens.json` — те же значения в JSON для передачи в Figma/генераторы.
- `components.css` — готовые классы `.em-*` (кнопки, бейдж, синяя карточка, тариф, поля, чекбокс, FAQ) поверх токенов. Подключать после `tokens.css`.
- `assets/fonts` — локальная копия Montserrat (OFL) для офлайн-витрины.
- `styleguide.html` — живая витрина компонентов на этих токенах (открывается локально, без сборки).

Быстрый старт:

```html
<link rel="stylesheet" href="tokens/tokens.css">
<link rel="stylesheet" href="components.css">
<body class="em-body">
  <button class="em-btn em-btn--primary">ПРИНЯТЬ УЧАСТИЕ</button>
</body>
```
