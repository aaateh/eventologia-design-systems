Дизайн-система страницы курса Ивентологии. Собрана по архивной копии event-manager1.eventologia.ru и исходному CSS.

Снимок 10/07/2026 · Montserrat · 34 цвета в CSS сведены к 25 ролям · прямые углы · оранжевый только для действия

Принципы

Пять правил, которые удерживают стиль страницы.

1. Ч/Б основа

Белый, чёрный и тёмно-серый — 90 % площади. Оранжевый — только действие и акцент.

2. Прямые углы

Кнопки, карточки, бейджи и поля без радиуса. Круглые — только аватары и кнопка закрытия.

3. Толстые заголовки

Montserrat 800, 36–50 px, ручные переносы, 2–4 строки. На мобильных — 28 px.

4. Полосы-секции

Ритм задаёт фон: белый → серо-зелёный → чёрный → светло-голубой. Без рамок между блоками.

5. Фото и люди

Крупные живые фотографии и круглые портреты вместо иллюстраций и абстракций.

6. Минимум эффектов

Только смена цвета за 0.2 s. Одна тень на всю страницу — у фото сертификата.

Белый — на фото и #0d0d0d, 268 px в хедере и 265 px в футере
