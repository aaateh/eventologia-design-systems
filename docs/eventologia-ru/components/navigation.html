Мобильная панель

≤ 750 px · .ev-panel

На узком экране слоган и контакты скрываются, справа появляется гамбургер 30 × 18. Панель шириной 320 px выезжает из-за правого края, фон затемняется на rgba(0, 0, 0, .8).

  • Пункты меню — вертикально, padding 14 px 24 px, активная «Афиша» выделена цветом.
  • Закрытие — по клику на затемнение, по Esc и по кнопке закрытия; фокус возвращается на гамбургер.
  • Фокус внутри панели замыкается по Tab, прокрутка страницы блокируется.
  • При prefers-reduced-motion анимация отключается, панель появляется сразу.

Кнопка показывает настоящую панель на десктопе. На телефоне её открывает гамбургер в шапке.
