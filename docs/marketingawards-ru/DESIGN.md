# Дизайн-система — marketingawards.ru («Суровая премия»)

> Источник: https://marketingawards.ru | Дата: 31/10/2026 | Уровень: Completo + проверка computed-стилей в браузере | Страницы: `/` (единственный экран)
>
> Сайт — одностраничное приложение (Vite + React). Разметка собирается JS, стили — один бандл `/assets/index-Bj4pxjPM.css`. Значения ниже сняты с вычисленных стилей живого DOM при ширине 1441px и сверены с CSS. Форма заявки открывается **внешним Salebot-лендингом** и к системе не относится (см. раздел 5).

**Быстрый старт.**
- Фон — почти чёрный `#080607`, текст — тёплый белый `#F5F0EB`. Других цветов в интерфейсе нет: акцента нет, кнопки прозрачные.
- Заголовок — `Dela Award` (Dela Gothic One), 400, **капс**, ~60px, межстрочный 1.06, трекинг −0.012em.
- Текст и кнопки — `Involve` (только 400), база — `Golos Award` 16px.
- Кнопки — 244×54, радиус **4px**, рамка 1px `#C8C2BC`; у главной кнопки рамка «горит» (canvas-слой).
- Отступ от края — `clamp(24px, 4vw, 72px)`; контент по центру, колонка 1040px.

## 3. Кнопки

### 3.1 Главная — `.star-border.apply-button`

| Параметр | Значение |
|---|---|
| Размер | 244×54 (`.page { --action-width / --action-height }`), на ≤599 — 238×52 |
| Радиус | 4px (`--star-border-radius`) |
| Рамка | 1px `#C8C2BC` через `box-shadow: inset 0 0 0 1px` (толщина `--star-border-thickness`) |
| Фон | прозрачный (`--star-border-surface: transparent`) |
| Текст | `#F5F0EB`, `Involve` 15px |
| Hover | фон `#15111280` |
| Focus | `outline: 2px solid #C8C2BC; outline-offset: 3px` |
| Disabled | `opacity: .5`, `cursor: not-allowed` |

Внутри — `<canvas class="star-border__light" aria-hidden="true">` 340×150: слой на 48px больше кнопки с каждой стороны, `z-index: -1`, `pointer-events: none`. Он рисует бегущий блик по рамке — белый, без цветных фильтров.

### 3.2 Вторичная — `.organizers-button`

- Те же 244×54 и радиус 4px.
- Рамка `1px color-mix(in srgb, currentColor 55%, transparent)`, фон прозрачный.
- Hover — фон `color-mix(in srgb, var(--ground) 50%, transparent)` → 65%.
- На ≤900px шрифт 12px, `gap: 12px`; на ≤599px `max-width: 166px`, `min-height: 44px`.

### 3.4 Реализация эффекта (рабочий код)

Эффект вынесен в `star-border.js` — порт canvas-компонента из бандла сайта. Математика сохранена: путь по скруглённому прямоугольнику (4 отрезка + 4 дуги), бегущий блик с градиентным хвостом, свечение головы, искры, вспышка по клику и «лишний круг» при наведении.

```html
<a class="star-border apply-button" href="…"
   style="--star-border-radius:4px;--star-border-thickness:1px;--star-border-track:#c8c2bc">
  <canvas class="star-border__light" aria-hidden="true"></canvas>
  <span>Заполнить</span>
</a>
<script src="star-border.js"></script>
<script>StarBorder.initAll();</script>
```

Параметры `StarBorder.init(el, opts)` и их значения по умолчанию (как на сайте):

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `duration` | 4 | секунд на полный оборот блика |
| `thickness` | 1 | толщина линии, px |
| `radius` | 4 | радиус скругления пути |
| `trailLength` | 0.3 | длина хвоста, доля периметра |
| `stars` | 1 | сколько бликов бежит одновременно (1–6) |
| `glow` | 0.6 | сила свечения (0–1) |
| `sparkle` | false | звёздочки на голове блика |
| `direction` | `clockwise` | направление |
| `hover` | `lap` | `lap` — лишний круг при наведении, `brighten`, `reveal` (блик стартует от курсора), `none` |
| `clickPulse` | true | вспышка от точки клика |
| `theme` | `dark` | `dark` — белый блик, `light` — тёмный |
| `paused` | false | остановить анимацию |
| `respectReducedMotion` | true | при `prefers-reduced-motion` блик не бежит |

Технические детали, которые важно сохранить при переносе:

- Canvas больше кнопки на 48px с каждой стороны (константа `BLEED`), позиционируется `top/left: -48px`, размер `calc(100% + 96px)`; плотность — `min(devicePixelRatio, 2)`.
- Рисование идёт со сдвигом `(48 + thickness/2) * dpr`, поэтому линия ложится ровно по рамке, а не по её внешнему краю.
- Хвост рисуется 90 короткими отрезками с квадратичным затуханием; у головы — радиальный градиент.
- Цвет блика — белый `#ffffff` (`theme: "dark"`). Никаких цветных фильтров и свечений на canvas не накладывается: акцентных цветов в системе нет.
- Анимация останавливается, когда кнопка вне вьюпорта (`IntersectionObserver`), и возобновляется при появлении.
- `aria-hidden="true"` на canvas — эффект декоративный.

### 3.3 Базовые правила `.apply-button` (до переопределения в `.page`)

`Geologica Award` 15px, `min-width: 260px`, `min-height: 58px`, `padding: 17px 22px`, `gap: 70px`, `justify-content: space-between`; иконка-стрелка 22px, при hover `translate(4px)`. В текущей сцене кнопка сжата до 244×54 и стрелки не имеет.

## 4. Формы и инпуты

**На самом сайте форм нет.** Единственная форма — внешний лендинг Salebot, который открывается по кнопке «Заполнить» (`salebot.site/st/bw6e/...`) в отдельном окне.

Его вид к системе **не относится** и не должен с ней смешиваться: там `Nunito`, синяя кнопка Telegram `#2DA4D7`, поля 46px с рамкой `#E1E6F0`, чекбоксы 20px — это чужой UI.

Если форма понадобится внутри сайта — собирать её на светлых токенах (`--paper` / `--ink` / `--field-line` / `--error`) с радиусом 4px и рамкой 1px, как кнопки.

## 7. Сетка, отступы, радиусы, тени

```css
.page {
  min-height: 100svh;
  display: grid;
  grid-template-rows: 96px 1fr auto;   /* шапка-зона / контент / подвал */
  background: var(--ground);
  color: var(--scene-ink);
  overflow: clip;
  isolation: isolate;
  --edge: clamp(24px, 4vw, 72px);
}
```

- `.intro` — `width: calc(100% - 2*var(--edge)); max-width: 1040px; margin: 24px auto; gap: 32px;` (до ≤900 — 1180px).
- `.brand-stage` — логотип, 44% ширины блока.
- `.hero-details` — `display: grid; justify-items: center; gap: 24px`.
- `.invitation-block` — колонка по центру, `gap: 24px`, ширина по контенту (356px).
- Ритм по вертикали: 96px сверху, затем центр, подвал 14/24px. На ≤900 — 88px.
- Радиусы: **4px** — кнопки; 6px — мелкие контролы; 40px — пилюли в альтернативной «арт»-раскладке; 3px — поля служебной панели.
- **Теней нет.** Глубина — только фон `#080607` и свечение canvas-слоя.

### 7.1 Паттерн экрана

Один экран на всю высоту: сверху пустая зона 96px → по центру логотип-вордмарк, под ним слоган в две строки, подпись и кнопка → внизу подвал с одной ссылкой. Фон — частицы огня на весь экран. Никаких секций, карточек и скролла.

## 8. Иконография и изображения

- **Логотип** — SVG-вордмарк `viewBox="0 0 230 45"`, 458×90 в рендере, две части: оранжевая `#F56624` и белая `#F5F0EB`. Оранжевый живёт только внутри файла логотипа и в палитру системы не входит. Лежит рядом: `logo.svg`. В разметке — `role="img"`, `aria-label="Суровая премия"`.
- Других иконок и картинок нет.
- **Фон** — WebGL/2D-canvas `canvas.fire-sparks` на весь экран, `pointer-events: none`, `aria-hidden`. Это не картинка и не градиент.
- В CSS объявлены и другие сцены-эффекты: `plasma`, `light-pillar`, `silk`, `liquid-chrome`, `dark-veil`, `iridescence`, `filmed-fire` (видео огня, `mix-blend-mode: screen`). В базовом экране активна `fire-dense`.

## Заметки

### Карта файлов

| Что | Где |
|---|---|
| HTML-оболочка | `/index.html` (5 КБ, монтирует приложение) |
| Стили | `/assets/index-Bj4pxjPM.css` (67 КБ, один бандл) |
| JS | `/assets/index-*.js` (React) |
| Шрифты | на сайте `/assets/*.woff2`; копии четырёх нужных файлов — в `fonts/` рядом с гайдом |
| Логотип | инлайн-SVG в DOM, копия — `logo.svg` |
| Эффект кнопки | canvas-блик; рабочий порт — `star-border.js` |

### Как это устроено

- Экран — CSS Grid `96px 1fr auto`; `overflow: clip` + `isolation: isolate` держат canvas-фон внутри.
- Облик задаётся переменными сцены на `.page`: `--ground`, `--scene-ink`, `--slogan-*`, `--invitation-*`, `--action-*`. Класс сцены — `variant--fire-dense`.
- Заголовок и подпись масштабируются от одной переменной `--display-size`, поэтому менять кегль нужно в одном месте.
- «Горящая» рамка кнопки — не CSS-градиент, а canvas 340×150 с бликом, вынесенным за границы кнопки на 48px.

### Чего в системе нет (не добавлять)

- Форм, инпутов, селектов, чекбоксов — их рисует внешний Salebot.
- Карточек, секций, скролла — экран один.
- Теней, градиентов, цветных плашек: глубина только за счёт фона и свечения.
- Иконок: единственный графический элемент — логотип.
- Акцентных цветов — их нет вовсе. Кнопки прозрачные, единственный цвет текста — `#F5F0EB`; оранжевый остаётся только внутри файла логотипа.
