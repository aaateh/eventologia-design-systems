Whiteconf.ru

«Белая конфа»: синий акцент #0026FC, CA Saygon в заголовках и Montserrat в тексте, заголовки без капса, кнопки прямоугольные с рамкой 4px. 12 разделов — от палитры и токенов до карточек спикеров, тарифов и корзины.

Полный текст гайда — DESIGN.md, переменные и компоненты — tokens.css.

5. Вход и регистрация

На сайте нет авторизации, регистрации и личного кабинета. В шапке и подвале нет ссылок «Войти»; personal.php — это страница согласия на обработку данных, а не кабинет. Ближайший «форменный» паттерн — попапы.

Правила
  • Оверлей .overlay — rgba(0,38,252,.75), z-index 300; попап — 301.
  • Крестик .btn_close — 35×35, круг, фон синий.
  • Подписей у полей нет — только placeholder с *.
  • Галочка согласия — 20×20, по умолчанию пустая.
  • Попапы: покупка доклада, бесплатный доклад, cookie-плашка.

12. Каталог блоков страниц

Что из каких блоков собрано на живых страницах сайта.

Главная /

Hero на фото → тёмный блок спикеров с переключателем потоков → тарифы → рассрочка → организаторы → подвал. Шапки нет.

Программа /program

Фиксированная шапка → заголовок 42px → вкладки «Таблица / Список» → таблица с sticky-временем → кнопки «Скачать» и «Купить» → подвал.

Потоки /potoki

Тёмная шапка 185px → заголовок 70px с контуром → слайдер белых карточек → CTA на фоне → подвал.

FAQ /faq

Шапка nav_black → заголовок 40px синий → список вопросов с прочерком → подвал.

Попапы

Покупка доклада (тёмный, 672px), бесплатный доклад, корзина-шторка 420px, cookie-плашка.

404

Шапка, сообщение, ссылка на главную, подвал. Отдельная страница 404.php.
