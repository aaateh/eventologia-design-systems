### 1.4 Правила использования

- Новых оттенков не вводить. В `style.css` синий — **`#0026FC`**, в `program.css` и новых компонентах (корзина, тёмный попап) — **`#0021FF`**. Это одно и то же «белое» синее, разница в 1% канала; смешивать в одном блоке не стоит.
- Глубина делается **рамкой и фоном**, а не тенями: тариф — рамка 3px (≤1300 — 2px) синим; карточка программы — рамка 1px `#DDDDDD` + радиус 10px.
- Тёмные секции — чистый `#1D1D1F`, не серый. Текст на них только белый.
- **Синий текст на тёмном фоне не читается** (`#0026FC` на `#1D1D1F` — 2.15:1). На тёмном синий допустим только как фон кнопки или тонкая рамка/иконка.
- Красный в системе — только служебный (ошибки, счётчик, cookie). В основных блоках его нет.

## 2. Типографика

### 2.1 Подключение шрифтов

- `@font-face` — в `fonts/stylesheet.css` (подключается в `include/head.php` строкой `<link rel="stylesheet" href="/fonts/stylesheet.css">`).
- **CA Saygon** — Regular (400) и Bold (700), woff2 + woff. Дисплейная гарнитура: заголовки, кнопки, названия спикеров. Широкие округлые глифы, узнаваемая «а».
- **Montserrat** — 200 ExtraLight (объявлен, в CSS не используется), 300 Light, 400 Regular, 800 ExtraBold. Текст, интерфейс, тарифы.
- **Proxima Nova** 800 — объявлена, используется **один раз**: `.trigger__top` (легаси-блок с градиентным текстом). В системе это не второй шрифт, а исключение.
- **DINCyr** — указан в `.faq_title` и `.faq_time_title`, но `@font-face` для него нет: фактически работает фолбэк. Не использовать в новых блоках.
- В `tokens.css` шрифты лежат рядом в `fonts/` (копии с сайта), добавлен `font-display: swap`.

### 2.2 База

```css
/* css/style.css: сброс */
html, body, div, span, … { font: inherit; font-size: 100%; }
html { line-height: 1; }

/* css/style.css */
body, input, button, textarea { font-family: "Montserrat"; }

/* css/them.css */
body { margin: 0; font-size: 16px; line-height: 1.2; }
```

Фактически в браузере: `font-family: Montserrat`, `font-size: 16px`, `line-height: 16px` (то есть 1.0 — сброс `html{line-height:1}` перебивает 1.2 из `them.css`). Для текста это слишком плотно, поэтому в каждом блоке высота строки задаётся вручную (1.25–1.5).

### 2.4 Особенности

- Заголовки **не капсом** (в отличие от «Сурового форума»): используется естественный регистр CA Saygon. Капс — только у названий тарифов, дня программы и заголовков попапов.
- Трекинг нигде не задан (`letter-spacing: normal`), кроме `.pop_part_new .pop_partner_title` (0.23px) и `.trigger__top` (−11px, легаси).
- **Контурный текст** — главный типографический приём: `.main-screen__title span` и `.stroke-txt` (страница потоков) — прозрачная заливка + `-webkit-text-stroke: 1px #FFF`.
- Заголовки-плакаты стоят на фотографии без подложки, поэтому у мелкого правого текста hero есть `text-shadow: 0 1px 2px rgba(0,0,0,.8)`.
- Основной текст в светлых блоках — Montserrat 300 (не 400), это даёт «журнальную» лёгкость. Не заменять на 400 без причины.
- Вёрстка без `hyphens`; длинные темы докладов переносятся естественно (`overflow-wrap: break-word` только в попапе покупки).

- Бургер — `<div class="hamburger-menu">` без `role`, `tabindex` и `aria-label`; открытие только мышью/тапом. Если трогаете шапку — заменить на `<button aria-expanded>`.
- У полей в попапах нет `<label>` — только `placeholder`. Для доступности нужен `aria-label` на каждом поле.
- У фото спикеров `alt=""` — это допустимо, потому что имя и тема идут текстом рядом. Логотип компании тоже `alt="Логотип"` (неинформативно, но не критично).

### Особенности

1. **Два синих.** `#0026FC` в `style.css`, `#0021FF` в `program.css` и новых компонентах. Визуально неотличимы, но в CSS это разные значения — не удивляйтесь при сравнении.
2. **Шапка на главной отключена** (закомментированный include). Поэтому на главной нет меню и телефона — только hero и соцсети. Любая новая главная должна либо вернуть `nav.php`, либо жить без шапки.
3. **Подмена viewport** для экранов < 641px (см. 9.1) — тестировать мобильную версию только в эмуляции устройства, иначе получите 375px на десктопе.
4. **Синий дуотон** на фото — не фильтр, а `mix-blend-mode: color` с `opacity:.7`. На светлых фото эффект сильнее, на тёмных — почти чёрный.
5. **Галочка согласия** тянется с `eventologia.ru` — внешняя зависимость. В `tokens.css` заменена на inline-SVG.
6. **Шрифт DINCyr** указан в FAQ, но файла нет — фактически фолбэк. Не тиражировать.
7. **Старые таблицы** `program2021…program2023` живут в том же `style.css` (классы `.program2021` и т.д.) — это архив, не часть актуальной системы.
8. **Легаси-цвета** `#6B81FF`, `#F01A24`, `#D8D9DA`, `#ECECEC` встречаются только в архиве и cookie-плашке.

- Личного кабинета, авторизации, регистрации — нет.
- Страниц спикеров на проде — нет (404), хотя шаблон и стили существуют.

- Иконочного шрифта — нет, только SVG.

### Чек-лист новой страницы

1. Подключить `include/head.php` (там же `them.css`, шрифты, `animations.css`, `style.css`, cookie).
2. Обёртка `<div class="main">` + `<div class="container">`; контейнер сам сужается по брейкпоинтам.
3. Шапка: `include "include/nav.php"` (абсолютная) или обёртка `.nav-bg-wrap.fixed` + `nav_black.php` (фиксированная). Для главной-лендинга можно без шапки — как на текущей главной.
4. Заголовок — `.title` (CA Saygon 700) + размер из таблицы 2.3; контурные акценты — `.stroke-txt`.
5. Кнопки — `.btn` + вариант; на тёмном — `.btn_blue` + `.btn_white`; в hero — высота 60px.
6. Формы — только в попапах: светлый `.inp-partner` или тёмный `.pop_part_new`.
7. Фото — квадрат, радиус 5px, `object-fit:cover` + синий дуотон через `::after`.
8. Не забыть `:focus-visible` для интерактивных элементов (сайт этого не делает).
9. Проверить на 1440, 1024, 768 и 375 (эмуляция устройства — из-за подмены viewport).
10. Проверить, что синий текст не попал на тёмный фон (`#0026FC` на `#1D1D1F` — 2.15:1).
